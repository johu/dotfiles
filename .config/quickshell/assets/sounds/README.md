Clock sounds, own work (synthesized with pure Python + ffmpeg, free to use, no third-party licence).
- alarm.ogg: ~34 s soft marimba piece that slowly gets fuller; loops up to 5 min, then "Missed alarm".
- timer.ogg: 3 s marimba arpeggio, repeated until the timer is dismissed.
Override in launcher-config.json: clockAlarmSound / clockTimerSound (absolute paths), volume: clockVolume (0..1).
The generator (synth.py) lives in ~/docs/quickshell/drafts/clock-sounds/.
